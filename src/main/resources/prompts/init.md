# 项目规则初始化任务
通过现有工具分析当前工作区，创建或更新根目录 AGENTS.md。遵守当前工作模式和权限，PLAN 只输出建议，禁止绕过审批。
先检查根目录和已有 AGENTS.md，再选择阅读 README、构建配置、关键源码入口与现有设计文档。无需遍历所有源码。
AGENTS.md 是 AI 编码助手的简短工作入口，不是详细的人类文档。只记录已确认的信息；不编造命令、目录或团队规范，也不把建议写成已有约定。
内容优先包括：一句话项目概述和技术栈；少量关键目录及作用；非显而易见的构建/测试/启动命令及环境前提；必要架构和编码约束；说明何种任务应读取哪些已有文档的路径索引。
详细信息引用已有文档，不复制全文；无需新建其他文档。不要写入密钥、个人隐私、临时任务进度、未经执行的验证结论。
尽量小于 1000 token 和 200 行，加载默认上限为估算 2000 token、32768 字节；中文文本也需保持简短。上限是约束，不是需要填满的目标。
已有文件时必须先读取，保留用户有效规则，只做有证据支持的针对性编辑，不整份覆盖。若规则过大则精简重复内容并保留文档索引。
写入使用 write_file 或 edit_file，遵守工具要求的先读、覆盖和审批规则。完成后重新读取确认内容；审批拒绝或工具失败时如实说明，禁止声称已保存。
